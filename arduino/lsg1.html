Aufgabe 2: Vollständiger Sketch

int ledPin = 13; int tasterPin = 8; int tasterStatus; void setup() { pinMode(ledPin, OUTPUT); // LED = Ausgang pinMode(tasterPin, INPUT); // Taster = Eingang } void loop() { tasterStatus = digitalRead(tasterPin); // Pin lesen if (tasterStatus == HIGH) { digitalWrite(ledPin, HIGH); // LED an } else { digitalWrite(ledPin, LOW); // LED aus } }
Erklärung: pinMode(tasterPin, INPUT) konfiguriert Pin 8 als Eingang. digitalRead(tasterPin) gibt HIGH zurück, wenn der Taster gedrückt ist (5V über Taster), und LOW, wenn er nicht gedrückt ist (Pull-down zieht auf GND).

Aufgabe 4 (Zusatz): LED blinkt bei gedrücktem Taster

void loop() { tasterStatus = digitalRead(tasterPin); if (tasterStatus == HIGH) { digitalWrite(ledPin, HIGH); delay(200); digitalWrite(ledPin, LOW); delay(200); } else { digitalWrite(ledPin, LOW); } }
Hinweis: Durch die delay(200)-Aufrufe reagiert der Arduino verzögert auf das Loslassen des Tasters. Für eine bessere Lösung könnte man millis() statt delay() verwenden.
