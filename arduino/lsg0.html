Aufgabe 1 + 2: Blink-Sketch und Geschwindigkeit

Kontrolle: Die LED blinkt im Sekundentakt. Für schnelleres Blinken beide delay(1000) durch delay(200) ersetzen, für langsameres durch delay(2000). Nach jeder Änderung neu hochladen (Pfeil-Button).

Aufgabe 3: Wartezeiten in Variablen auslagern

int ledPin = 13; int zeitAn = 1000; // Leuchtdauer in ms int zeitAus = 1000; // Dunkeldauer in ms void setup() { pinMode(ledPin, OUTPUT); } void loop() { digitalWrite(ledPin, HIGH); delay(zeitAn); digitalWrite(ledPin, LOW); delay(zeitAus); }

Aufgabe 4: Tastgrad berechnen

t = 500 ms,   T = 500 ms + 1000 ms = 1500 ms
g = 500 / 1500 · 100 % ≈ 33 %
Achtung: T ist die gesamte Periodendauer (an + aus) — nicht nur die Aus-Zeit! Im Sketch: zeitAn = 500, zeitAus = 1000.

Aufgabe 5: Tastgrad 25 % bei T = 2 s

t = g · T = 0,25 · 2000 ms = 500 ms
zeitAn = 500 ms,   zeitAus = 2000 − 500 = 1500 ms

Aufgabe 6: Lauflicht — vollständiger Sketch

int ledPin[] = {7, 8, 9, 10, 11, 12, 13}; // Array mit 7 Pins int wartezeit = 200; // Pause in ms void setup() { for (int i = 0; i < 7; i++) { pinMode(ledPin[i], OUTPUT); // alle 7 Pins als Ausgang } } void loop() { for (int i = 0; i < 7; i++) { digitalWrite(ledPin[i], HIGH); // LED i an delay(wartezeit); digitalWrite(ledPin[i], LOW); // LED i wieder aus } }

Aufgabe 7: Was bedeutet ledPin[i] bei i = 3?

Antwort: Pin 10. Arrays zählen ab 0: ledPin[0] = 7, ledPin[1] = 8, ledPin[2] = 9, ledPin[3] = 10.

Aufgabe 8 (Zusatz): Knight Rider — hin und zurück

void loop() { for (int i = 0; i < 7; i++) { // vorwärts: 0,1,...,6 digitalWrite(ledPin[i], HIGH); delay(wartezeit); digitalWrite(ledPin[i], LOW); } for (int i = 5; i > 0; i--) { // rückwärts: 5,4,...,1 digitalWrite(ledPin[i], HIGH); delay(wartezeit); digitalWrite(ledPin[i], LOW); } }
Warum 5 bis 1? Die Endpunkte (6 und 0) leuchten schon in der Vorwärts-Schleife — so blinkt an den Rändern nichts doppelt.

Häufige Fehler

Typische Stolperfallen:
  • LED-Polung: Langes Bein (Anode) Richtung Pin, kurzes Bein Richtung GND. Falsch herum = LED bleibt dunkel.
  • Vorwiderstand vergessen: Nie eine LED direkt an einen Pin — 220–330 Ω schützen LED und Arduino.
  • delay() rechnet in Millisekunden: delay(1) ist 1 ms, nicht 1 s. Eine Sekunde = delay(1000).
  • Array-Grenze: i < 7, nicht i <= 7 — sonst greift die Schleife auf ledPin[7] zu, das es nicht gibt.
  • Semikolon vergessen: Der Compiler meldet den Fehler oft erst in der nächsten Zeile.
