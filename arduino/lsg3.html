Aufgabe 2: Vollständiger Sketch

int sensorPin = A0; int ledGruen = 11; int ledGelb = 12; int ledRot = 13; int sensorWert; void setup() { pinMode(ledGruen, OUTPUT); pinMode(ledGelb, OUTPUT); // gelbe LED pinMode(ledRot, OUTPUT); // rote LED Serial.begin(9600); } void loop() { sensorWert = analogRead(sensorPin); Serial.println(sensorWert); if (sensorWert < 400) { // kalt: nur grün an digitalWrite(ledGruen, HIGH); digitalWrite(ledGelb, LOW); digitalWrite(ledRot, LOW); } else if (sensorWert < 600) { // warm: nur gelb an digitalWrite(ledGruen, LOW); digitalWrite(ledGelb, HIGH); digitalWrite(ledRot, LOW); } else { // heiß: nur rot an digitalWrite(ledGruen, LOW); digitalWrite(ledGelb, LOW); digitalWrite(ledRot, HIGH); } delay(200); }
Die Lücken:
• pinMode(ledGelb, OUTPUT) und pinMode(ledRot, OUTPUT)
• else if (sensorWert < 600)
• Im kalt-Block: grün = HIGH, gelb = LOW, rot = LOW
• Im warm-Block: grün = LOW, gelb = HIGH, rot = LOW
• Im heiß-Block: alle drei digitalWrite-Aufrufe ausschreiben

Aufgabe 3: Schwellwerte anpassen

Die Schwellwerte 400 und 600 sind Startwerte. Nach dem Testen sollten die Werte so angepasst werden, dass die Übergänge zur beobachteten Temperatur passen.

BereichSchwellwert (Beispiel)LED
kaltSensorwert < 350grün
warm350 ≤ Sensorwert < 550gelb
heißSensorwert ≥ 550rot
Tipp: Nutzen Sie den Serial Monitor (AB 2), um die tatsächlichen Sensorwerte bei verschiedenen Temperaturen abzulesen und die Schwellwerte gezielt einzustellen.

Aufgabe 5 (Zusatz 1): Taster + Temperaturmessung

int tasterPin = 8; void setup() { pinMode(ledGruen, OUTPUT); pinMode(ledGelb, OUTPUT); pinMode(ledRot, OUTPUT); pinMode(tasterPin, INPUT); Serial.begin(9600); } void loop() { if (digitalRead(tasterPin) == HIGH) { // Taster gedrückt: Temperatur messen sensorWert = analogRead(sensorPin); Serial.println(sensorWert); if (sensorWert < 400) { digitalWrite(ledGruen, HIGH); digitalWrite(ledGelb, LOW); digitalWrite(ledRot, LOW); } else if (sensorWert < 600) { digitalWrite(ledGruen, LOW); digitalWrite(ledGelb, HIGH); digitalWrite(ledRot, LOW); } else { digitalWrite(ledGruen, LOW); digitalWrite(ledGelb, LOW); digitalWrite(ledRot, HIGH); } } else { // Taster nicht gedrückt: alle LEDs aus digitalWrite(ledGruen, LOW); digitalWrite(ledGelb, LOW); digitalWrite(ledRot, LOW); } delay(200); }
