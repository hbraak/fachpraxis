Teil 2 — Serial Plotter

Aufgabe 2: Kleinster Wert ≈ 0 (ein Anschlag), größter Wert ≈ 1023 (anderer Anschlag). Das Poti nutzt also den vollen ADC-Bereich – anders als der NTC.
Aufgabe 3 — Rohwert → Spannung:
U = wert · 5 V / 1023. Bei wert = 512:
U = 512 · 5 / 1023 ≈ 2,50 V (also genau die Mitte).

Teil 3 — map()

map(512, 0, 1023, 0, 255) = 512 · 255 / 1023 ≈ 127.

Teil 4 — LED-Dimmer (Lösung)

int potiPin = A0; int ledPin = 9; // PWM-Pin (~) int wert, helligkeit; void setup() { pinMode(ledPin, OUTPUT); } void loop() { wert = analogRead(potiPin); // 0 ... 1023 helligkeit = map(wert, 0, 1023, 0, 255); // Luecke: 255 analogWrite(ledPin, helligkeit); delay(20); }
Aufgabe 4: Lücke = 255. Beim Drehen wird die LED stufenlos heller bzw. dunkler – weil analogWrite() über PWM die mittlere Spannung an der LED verändert.

Teil 5 — Servo (Lösung)

#include <Servo.h> Servo meinServo; int potiPin = A0; int wert, winkel; void setup() { meinServo.attach(9); } void loop() { wert = analogRead(potiPin); // 0 ... 1023 winkel = map(wert, 0, 1023, 0, 180); // Luecke: 180 meinServo.write(winkel); delay(20); }
Aufgabe 5: Winkelbereich = 0 … 180. Die Poti-Stellung wird proportional auf den Servo-Winkel abgebildet: linker Anschlag → 0°, Mitte → 90°, rechter Anschlag → 180°.

Teil 6 — Digitalisierung & Auflösung

Aufgabe 6 (Treppen im Plotter): Der ADC kennt nur 1024 diskrete Stufen. Zwischenwerte gibt es nicht – deshalb springt die Kurve in kleinen Stufen statt glatt zu steigen. Das ist die Quantisierung.
Aufgabe 7 (Spannungsauflösung):
ΔU = 5 V / 1024 ≈ 4,9 mV. Spannungsunterschiede kleiner als ~4,9 mV kann der Arduino-Uno nicht unterscheiden.

Aufgabe 8 (Zusatz): Spannung ausgeben

void loop() { wert = analogRead(potiPin); float U = wert * 5.0 / 1023; // Rohwert -> Spannung Serial.println(U); // z.B. 2.50 delay(50); }
Mehr Auflösung gefällig? Mittelwert aus vielen Messungen (Oversampling), analogReference(INTERNAL) (1,1 V-Bereich) oder ein externer 16-Bit-ADC (ADS1115) – siehe AB 4.
