Warum Auflösung über den Projekterfolg entscheidet

Teil 1 — Abkühlkurve

Aufgabe 2: Es ist eine Kurve (kein Gerade) — sie fällt anfangs steil und wird zum Ende hin flach (exponentieller Verlauf).
Aufgabe 3: Schnell am Anfang (großer Temperaturunterschied zur Luft), langsam gegen Ende (kaum noch Unterschied zur Raumtemperatur).
Physik: Newton'sches Abkühlungsgesetz — die Abkühlrate ist proportional zur Temperaturdifferenz Körper ↔ Umgebung. Deshalb der exponentielle Verlauf.

Teil 2 — Auflösung

Aufgabe 4: ΔU = 3,3 V / 1024 ≈ 3,2 mV (gegenüber 4,9 mV bei 5 V — also feiner).
Aufgabe 5 (Sicherheit): Wird analogReference(EXTERNAL) erst nach einem analogRead() gesetzt, liegt die interne Referenz auf dem AREF-Pin und wird mit der externen Spannung kurzgeschlossen — das kann den Mikrocontroller beschädigen. Deshalb immer zuerst die Referenz setzen.

Teil 3 — Hauchdetektor (Lösung)

float basis; int ledPin = 8; float messe() { // Mittelwert aus 32 Messungen long summe = 0; for (int i = 0; i < 32; i++) summe += analogRead(A0); return summe / 32.0; } void setup() { analogReference(EXTERNAL); // 3,3 V an AREF pinMode(ledPin, OUTPUT); analogRead(A0); // erste Messung verwerfen basis = messe(); // Ruhewert merken Serial.begin(9600); } void loop() { float wert = messe(); Serial.println(wert - basis); if (wert > basis + 8) { // Schwelle ~8 (anpassen!) digitalWrite(ledPin, HIGH); } else { digitalWrite(ledPin, LOW); } delay(50); }
Aufgabe 6 (Schwelle): Typisch ~5–10 (ADC-Einheiten über dem Ruhewert). Sie muss über dem Restrauschen, aber unter dem Hauch-Signal liegen. Genauer Wert je nach NTC/Aufbau selbst einstellen.
Aufgabe 7 (Gegenprobe): Mit einer einzelnen analogRead() und der groben 5-V-Referenz flackert die LED schon in Ruhe — das Rauschen überschreitet die Schwelle ständig.
Aufgabe 8 (Fazit): Das Hauch-Signal ist nur wenige mV groß. Erst der Mittelwert (unterdrückt Rauschen) und die kleinere Referenz (feinere Stufen) machen dieses kleine Signal zuverlässig sichtbar. Ohne gute Auflösung kein Hauchdetektor — genau das ist der Kern des Themas.
