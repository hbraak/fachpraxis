Aufgabe 2: Vollständiger Sketch

int sensorPin = A0; int sensorWert; void setup() { Serial.begin(9600); // Serial Monitor starten } void loop() { sensorWert = analogRead(sensorPin); // Analog-Pin lesen Serial.print("Sensorwert: "); Serial.println(sensorWert); // Wert ausgeben delay(500); // 0,5 s warten }
Die Lücken:
• analogRead(sensorPin) — liest die Spannung an Pin A0 (Wert 0–1023)
• sensorWert — die Variable, die ausgegeben werden soll

Aufgabe 4: Erwartete Messwerte

SituationSensorwert (ca.)Erklärung
Raumtemperatur300 – 450NTC hat mittleren Widerstand
Mit Fingern festhalten450 – 600Körperwärme → RNTC sinkt → UA0 steigt
Mit Eiswürfel kühlen100 – 250Kalt → RNTC groß → UA0 klein
Mit Fön erwärmen600 – 900Heiß → RNTC sehr klein → UA0 groß
Hinweis: Die genauen Werte hängen vom konkreten NTC und der Umgebungstemperatur ab. Die Tendenz ist entscheidend!

Aufgabe 5: Zusammenhang

Wird der NTC wärmer, wird der Sensorwert größer.

Begründung: Im Spannungsteiler bilden NTC (oben) und 10 kΩ (unten) eine Reihenschaltung. Wenn die Temperatur steigt, sinkt der NTC-Widerstand. Dadurch fällt weniger Spannung über dem NTC ab und mehr über dem 10 kΩ-Widerstand. Da Pin A0 die Spannung über dem 10 kΩ-Widerstand misst, steigt der Sensorwert.

Aufgabe 6 (Zusatz): Text im Serial Monitor

void loop() { sensorWert = analogRead(sensorPin); Serial.print("Sensorwert: "); Serial.print(sensorWert); if (sensorWert < 400) { Serial.println(" -> kalt"); } else if (sensorWert < 600) { Serial.println(" -> warm"); } else { Serial.println(" -> heiss"); } delay(500); }
