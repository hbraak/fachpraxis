Lösung AB 4: Was bedeutet „analog"?

ADC-Auflösung, Kalibrierung und Grenzen

Aufgabe 1: Auflösung berechnen

a) Anzahl der Stufen

210 = 1024 verschiedene Stufen

b) Spannungsauflösung

ΔU = 5 V / 1024 = 4,88 mV ≈ 4,9 mV
Das bedeutet: Der Arduino kann Spannungsunterschiede von weniger als 4,9 mV nicht erkennen. Alles, was sich um weniger als ~5 mV ändert, bleibt für den ADC „unsichtbar".

c) ADC-Werte umrechnen

Aufgabe 3: Kalibrierung

a) Beispiel-Messwerte (1 kΩ NTC)

Wichtig: Die genauen Werte hängen stark vom konkreten NTC ab! Deswegen ist die Kalibrierung mit dem Thermometer so wichtig – nur so bekommen Sie eine verlässliche Zuordnung.

c) Linear oder nichtlinear?

Der Zusammenhang ist nichtlinear (Kurve). Der NTC-Widerstand ändert sich nicht gleichmäßig mit der Temperatur, sondern folgt einer Exponentialfunktion. Bei niedrigen Temperaturen ist die Änderung pro °C größer als bei hohen.

Aufgabe 4: map()-Funktion

a) Beispiel-Sketch mit Kalibrierwerten

int sensorWert; void setup() { Serial.begin(9600); } void loop() { sensorWert = analogRead(A0); // Kalibrierwerte: ADC 200 = 0°C, ADC 700 = 55°C int tempC = map(sensorWert, 200, 700, 0, 55); Serial.print("ADC: "); Serial.print(sensorWert); Serial.print(" Temperatur: "); Serial.print(tempC); Serial.println(" C"); delay(500); }
So funktioniert map():
map(wert, vonMin, vonMax, zuMin, zuMax)

Rechnet linear um: Wenn der ADC-Wert 200 ist → 0 °C. Wenn er 700 ist → 55 °C. Alles dazwischen wird proportional umgerechnet.

c) Warum ist map() nicht ganz korrekt?

map() rechnet linear um (Gerade). Der NTC hat aber eine nichtlineare Kennlinie (Exponentialfunktion). Die lineare Näherung funktioniert nur in einem kleinen Temperaturbereich einigermaßen gut. Für genauere Ergebnisse bräuchte man die Steinhart-Hart-Gleichung oder eine Lookup-Tabelle.

Aufgabe 5: Grenzen der Auflösung

a) Schwankung bei Raumtemperatur

Typisch: Der ADC-Wert schwankt um ±1 bis ±3 Stufen, auch wenn sich die Temperatur nicht ändert. Das ist normales „Rauschen" des ADC.

±2 Stufen × 4,9 mV = ±9,8 mV Rauschen

b) Kleinste messbare Temperaturänderung

Beispiel: Empfindlichkeit des Sensors bei Raumtemperatur ca. 10 mV/°C:

ΔTmin = 4,9 mV / 10 mV/°C = 0,49 °C ≈ 0,5 °C
Praxisproblem: Wenn das Rauschen schon ±10 mV beträgt und die Empfindlichkeit nur 10 mV/°C ist, dann „verschwindet" eine Temperaturänderung von 0,5 °C im Rauschen. Deshalb mussten Sie den NTC so stark erwärmen, um einen deutlichen Unterschied zu sehen!

c) Zusatz: ADS1115

Der ADS1115 ist ein externer 16-Bit-ADC, der über I²C (2 Drähte: SDA + SCL) an den Arduino angeschlossen wird. Vorteile:

  • 16-Bit Auflösung → 64× feiner als der Arduino-ADC
  • Programmierbarer Verstärker (PGA) → kann kleine Spannungen „zoomen"
  • 4 Eingänge (statt 1)
  • Anschluss: VCC, GND, SDA (→ A4), SCL (→ A5)
